# CV Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the standalone CV builder into this repo, add `npm run cv` to rebuild the committed PDF, and add a `/cv` page that shows the same CV with a Download PDF button, linked from the nav and the footer.

**Architecture:** `cv/template.mjs` renders `cv/content.json` to one HTML fragment (`<div class="cv">…</div>`). The `/cv` server page injects that fragment with `cv/cv.css` (every rule scoped under `.cv`). `cv/build.mjs` wraps the same fragment in a full document with `cv/print.css` (fonts, `@page`) and prints it to `public/<outputBasename>.pdf` with the installed Chrome. A hash of the sources, checked by a unit test, catches a forgotten rebuild.

**Tech Stack:** Node 24 ESM, Next.js 16.3.8 (App Router), React 19.3.0, TypeScript, CSS Modules plus one global stylesheet, `@playwright/test` 1.63.0 (for both PDF printing and e2e), Vitest 5 (jsdom).

**Spec:** `docs/superpowers/specs/2026-10-02-personal-website-design.md`, section 33 and decisions 231–236. The CV's own design (moved in Task 1): `docs/superpowers/specs/2026-10-20-cv-design.md`.

**Source folder (read only, never modified):** `/Users/kapantzak/Projects/kapantzakis-promotion/`.

## Global Constraints

- No new dependencies. The PDF build imports `chromium` from `@playwright/test` and launches it with `{ channel: "chrome" }`.
- PDF options, verbatim from the source build: `emulateMedia({ media: "print" })` after `document.fonts.ready`, then `page.pdf({ format: "A4", preferCSSPageSize: true, printBackground: true, tagged: true, outline: true, displayHeaderFooter: false })`.
- Paths: the PDF goes to `public/${cv.outputBasename}.pdf`, the build's HTML to `.tmp/cv/${cv.outputBasename}.html` (already gitignored), and the hash to `cv/sources.sha256`.
- Every `cv/cv.css` selector starts with `.cv`. The CV's custom properties are `--cv-fg`, `--cv-fg-soft`, `--cv-muted`, `--cv-rule` and `--cv-accent`, defined on `.cv` with the source values `#0b0d12`, `#2a2e37`, `#5a6070`, `#d9d6cc` and `#15533d`.
- Links to `/cv` are plain `<a>` elements, never `next/link` (decision 229).
- Copy:
  - The nav and footer link label is "CV".
  - The button text is "Download PDF".
  - The page title is "CV".
  - The page description is "Experience, open source, writing, skills and education, with a PDF to download."
  - The guard's failure message is "CV sources changed; run npm run cv".
- The owner's name may appear only in `content/profile.ts` and `cv/content.json` (decision 19, extended by decision 231). Code reads `profile.name` or `cv.name`. Docs say "the user".
- Code comments explain why and cite decision numbers, as the codebase does.
- Commit messages are a plain imperative sentence, with no prefixes and no tool attribution.
- Stage files by name and never run `git add -A`.
- Never modify or delete anything in the source folder.

## Review Focus

1. **A narrow phone (320px wide):** long contact links, the date rows and a nav that now has four items must not make the page scroll sideways. This is pinned in Task 2 (`fits a 320px-wide screen`).
2. **Site styles leaking into the sheet:**
   - The global `h1, h2, h3` rule (`styles/globals.css:49-61`) would turn the CV's `h3` into the display font.
   - `a:hover` (`globals.css:74`) would turn links lime on paper.
   - This is pinned in Task 2 (`keeps the CV's own type and link colour`).
3. **CV styles leaking out:** after a client navigation from `/cv` to the home page, `cv/cv.css` stays loaded, but the home page must look unchanged. This is pinned in Task 2 (`leaves the home page's styles alone after visiting`).
4. **Fonts not loading in the PDF build:** if the `<base>` or the font paths are wrong, Chrome silently prints Arial. The build must fail instead. This is pinned in Task 1, Step 7.
5. **Content with HTML-special characters:** `&`, `<` and `"` in any `content.json` value must be escaped in the page and the PDF. This is pinned in Task 1 (`escapes content`).

6. Close the browser in `finally`.
7. Write `(await sourcesHash()) + "\n"` to `cv/sources.sha256`.
