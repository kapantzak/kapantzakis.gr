# CV (PDF) design — 2026-10-20

Moved into the website repo on 2026-10-21; see the site spec, section 33.

## Intent
Replace the user's 4-page 2019-era CV with a modern, best-practice, 2-page A4 PDF that
reflects the content of the user's personal website (kapantzakis.gr), generated from a
single data file so it can be regenerated and tailored per application.

## Constraints (from research)
- Single column, real text, contact details in the body (not a page header/footer).
- Standard plain-text section headings, no icons, tables, skill bars, photo, references line.
- Body 10-11pt, margins >= 0.5in, consistent "Mon YYYY - Present" dates, one accent colour.
- Visible short URLs that are also clickable; max 4-5 contact links.
- Verify every build by plain-text extraction (reading order, no ligature glyph damage).

## Layout
- `cv/content.json`: all CV content (the CV's only file carrying personal data).
- `cv/template.mjs`: renders content to the `.cv` fragment and to the PDF's document.
- `cv/cv.css`: the styles the `/cv` page and the PDF share, scoped under `.cv`.
- `cv/print.css`: PDF only (A4 `@page`, `@font-face`, white page).
- `cv/fonts/`: self-hosted woff2 files for reproducible embedding.
- `cv/build.mjs` (`npm run cv`): renders the document to `.tmp/cv/`, prints the PDF via Playwright and records `cv/sources.sha256`. Verification is manual (README).
- `public/<outputBasename>.pdf`: the committed PDF, served by the site.
